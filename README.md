## Tech Stack

- Vue 3
- TypeScript
- Vite
- Tailwind CSS v4
- Vue Router

## Project Structure

- src/App.vue: Main portfolio layout and UI sections
- src/data/content.ts: Skills, experience, and project data
- src/types/index.ts: Shared TypeScript interfaces

## Getting Started

1. Install dependencies
  npm install

2. Start development server
  npm run dev

3. Build for production
  npm run build

4. Run linting
  npm run lint

## Customizing Content

To update portfolio content:

- Edit experience, skills, and projects in src/data/content.ts
- Edit layout, sections, and styling in src/App.vue
- Update interface models in src/types/index.ts when adding new fields
